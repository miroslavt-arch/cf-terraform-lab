## 0:52–1:12 — Topic 20: the human gate (the centrepiece)

Two parts: the pipeline, then the invariant underneath it.

### Part 1 — run the pipeline (live)

**RUN:**
```bash
git checkout -b demo/ttl-bump
sed -i 's/ttl     = 300/ttl     = 600/' infra/envs/lab/main.tf
git commit -am "demo: bump lab-hello TTL" && git push -u origin demo/ttl-bump
gh pr create --fill
```

**SAY while CI runs:** "The PR pipeline plans with a token that physically
cannot write — read-only permissions, held in the `lab-plan` environment. It
saves the plan as an artifact named after the commit SHA, runs the OPA destroy
guard against it, and posts the summary as a comment."

**SHOW:** the PR comment; the artifact name `tfplan-<sha>`; then Settings →
Environments → `lab-apply` with **required reviewer** and **1-minute wait
timer**.

**RUN:**
```bash
gh workflow run tf-apply.yml -f plan_run_id=<run-id> -f sha=<sha>
```

**SAY:** "Now watch: the job doesn't start. Wait timer counting down, then it
sits waiting for my approval. And when I approve, it does *not* re-plan — it
downloads that exact artifact and applies it."

### Part 2 — why the pinning matters

**RUN:**
```bash
bash scripts/demo-20-stale-plan.sh
```

**SAY:** "I saved a plan. Then someone changed a record out of band. Now I try
to apply the plan my reviewer approved —" (let the error land) "— *Saved plan
is stale.* Process can be skipped. This can't. The thing that was approved is
the only thing that can execute, and only against the world it was computed
for."

**Fallback if GitHub is down:** the stale-plan demo is fully local and makes

## 1:36–1:48 — Topic 29: brownfield adoption

**RUN:**
```bash
bash scripts/demo-29-adopt.sh
```

**SAY:** "Six resources that Terraform has never heard of — made by raw API
calls the way a dashboard user would. One `import` block with `for_each` over
a CSV adopts five of them; for the ruleset, Terraform writes the config
itself with `-generate-config-out`, and `normalize.py` strips the noise."

**SHOW (the counters — read them aloud):**
```
Plan: 5 to import, 0 to add, 0 to change, 0 to destroy.
Apply complete! Resources: 6 imported, 0 added, 0 changed, 0 destroyed.
No changes. Your infrastructure matches the configuration.
```

**SAY:** "`0 changed, 0 destroyed`, and the next plan says *No changes*. That
sentence is the certificate: adoption touched nothing. Nobody refactors until
you see it — because refactoring on top of a lie compounds the lie."

**War story worth telling:** the first time this ran it said `5 changed` —
the seeded content had an em-dash, Cloudflare stores non-ASCII in TXT as octal
escapes, and the config silently didn't match. The gate caught it. Without the
gate, "adoption" would have quietly rewritten five live records.
